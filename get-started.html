Get Started

Choose your path: server or client.

Telepact is designed so servers own the API schema and enforce compliance, while clients can start with plain JSON and optionally opt in to richer Telepact tooling.

For Servers

The Telepact API schema is drafted and owned by the server. You define your *.telepact.json schema, serve requests with a Telepact library, and the library performs request/response validation against your schema.

Current server library options: TypeScript, Python, Java, and Go.

TypeScript Python Java Go

1) Draft your schema

[
  {
    "fn.divide": {
      "x": "integer",
      "y": "integer"
    },
    "->": [
      { "Ok_": { "result": "number" } },
      { "ErrorCannotDivideByZero": {} }
    ]
  }
]

2) Serve it (Python example)

from telepact import TelepactSchemaFiles, TelepactSchema, Server, Message

schema_files = TelepactSchemaFiles("./api")
api = TelepactSchema.from_file_json_map(schema_files.filenames_to_json)

async def handler(req_msg):
    fn = req_msg.get_body_target()
    args = req_msg.body[fn]
    if fn == "fn.divide":
        x = args["x"]
        y = args["y"]
        if y == 0:
            return Message({}, {"ErrorCannotDivideByZero": {}})
        return Message({}, {"Ok_": {"result": x / y}})

server = Server(api, handler, Server.Options())
# server.process(request_bytes) validates request and response against schema

Language-specific server docs: TypeScript, Python, Java, Go.

For Clients

No Telepact client library is required. A client can connect to the server's transport and send JSON payloads with any preferred JSON/network library.

Clients can also opt in to Telepact libraries for improved type safety, code generation workflows, and binary encodings.

1) Plain JSON client (no library)

const request = [
  {},
  {
    "fn.divide": {
      x: 6,
      y: 3,
    }
  }
];

const response = await fetch("http://localhost:8000/api/telepact", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(request),
});

console.log(await response.json());
// -> [{}, {"Ok_": {"result": 2}}]

2) Optional Telepact client

import { Client, ClientOptions, Message } from "telepact";

const adapter = async (m, serializer) => {
  const requestBytes = serializer.serialize(m);
  const responseBytes = await transport.send(requestBytes);
  return serializer.deserialize(responseBytes);
};

const client = new Client(adapter, new ClientOptions());
const response = await client.request(
  new Message({}, { "fn.divide": { x: 6, y: 3 } })
);

if (response.getBodyTarget() === "Ok_") {
  console.log(response.getBodyPayload().result);
}

Optional tooling for client workflows: CLI, Browser Console, Prettier Plugin.
