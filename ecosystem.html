Libraries + Tools

Use Telepact from your current stack.

Telepact supports server and client implementation patterns in TypeScript, Python, Java, and Go, plus utility tooling for schema workflows and debugging.

Want the fastest onboarding route? Start at Get Started for server/client paths.

Language libraries

TypeScript

npm install telepact

Schema loading, request handling, and transport adapters for browser/node environments.

Reference

Python

pip install telepact

Async server/client flow with schema validation and serializer abstractions.

Reference

Java

<artifactId>telepact</artifactId>

JVM integration with strongly-typed message handling and adapter-based transport wiring.

Reference

Go

go get github.com/telepact/telepact/lib/go

Idiomatic Go server/client setup with pluggable transport send/receive boundaries.

Reference

SDK tooling

CLI

pipx install telepact-cli

Fetch API schemas, generate artifacts, and spin up mocks for test-time workflows.

Reference

Browser Console

npx telepact-console -p 8080

Interactive API exploration, live request execution, and doc-driven debugging.

Reference

Prettier Plugin

npm install prettier-plugin-telepact

Standardized formatting for *.telepact.json, especially docstring-heavy schemas.

Reference

JSON Schema

Validate schema files with a machine-readable contract for CI and editor integrations.
