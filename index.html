Open Source API Ecosystem

Build APIs once. Serve across boundaries.

Telepact bridges programs across inter-process communication boundaries with a JSON-first API model, optional binary efficiency, and built-in schema-driven validation.

Explore Repository Read telepact-api Skill

JSON as Query Language

Use native JSON for both calls and dynamic response shaping.

Binary, No Codegen Required

Runtime handshakes unlock compact binary protocols without forcing generated clients.

Hypermedia, Without HTTP Lock-In

Return callable functions with pre-filled args to model link-like flows over any transport.

Why Telepact

Combines the best parts of REST, gRPC, and GraphQL.

Accessibility

Start with plain JSON and standard networking APIs, then opt in to generated code and binary when needed.

Portability

Schemas become reusable ecosystem currency for docs, mocks, code completion, and tooling workflows.

Stability by Design

Schema constraints push API evolution toward backwards-compatible paths and clearer type intent.

Quick Start

Define an API, run a server, call it from anywhere.

1) Schema

[
  {
    "fn.divide": { "x": "integer", "y": "integer" },
    "->": [{ "Ok_": { "result": "number" } }, { "ErrorCannotDivideByZero": {} }]
  }
]

2) Request

[
  {},
  {
    "fn.divide": { "x": 6, "y": 3 }
  }
]

3) Response

[
  {},
  {
    "Ok_": { "result": 2 }
  }
]
